## E-001 應變能計算與 CalculiX 精確值比對（2026-11-21）
- 方法：取 M-001 的 AUTO_V0_LC1（X 向）與 AUTO_V0_LC0（自重）.inp，加 `*EL PRINT, ELSET=<零件>, TOTALS=ONLY` / `ELSE`，以 CalculiX 2.21 求解得各零件精確內能
- 原因 1：`read_inp` 不認得 C3D15（楔形）元素，主軸的 360 個 C3D15 元素被略過 → 主軸應變能少 7.9%
- 原因 2：原本用「節點應力（外插平均）內插」計算應變能，C3D10 粗網格偏低約 1.4%
- 修正：加入 C3D15/C3D6；應變能改為「節點位移 → 積分點應變 ε = B·u → σ = Dε → ∫½σ:ε」，與 CalculiX 相同；不認得的元素型別會發出警告

| 工況 | 零件 | 修正前 | 修正後 | CalculiX ELSE |
|---|---|---|---|---|
| X 向 | 底座 | 0.24457 | 0.247984 | 0.247984 |
| X 向 | 立柱 | 1.06468 | 1.064865 | 1.064866 |
| X 向 | 主軸頭 | 0.79628 | 0.801460 | 0.801460 |
| X 向 | 主軸 | 0.66276 | 0.719769 | 0.719769 |
| X 向 | 工作台 | 0.01113 | 0.011307 | 0.011307 |
| X 向 | 合計 | 2.77941 | 2.845385 | 2.845385（外力功 2.845384） |
| 自重 | 合計 | 8.64597 | 8.763457 | 8.763459（外力功 8.763455） |

- 回歸：V-007 總應變能 990.983 / 外力功 990.960（原 989.142）；A 佔比 82.95%（原 83.01%）。V-001 3.33347e-8 / 3.33344e-8（原 3.33232e-8）
