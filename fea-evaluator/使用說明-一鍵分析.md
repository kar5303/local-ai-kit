# 一鍵分析：自己的模型丟進 PrePoMax，其餘自動完成

## 你要做的
1. 開 PrePoMax 3.0.1，確認 **自動化（Automation）伺服器已啟用**（設定 → Automation），token 已放在 `mcp/prepomax_token.txt`。
2. 在 PrePoMax 建好你的模型：匯入幾何／網格、材料（**要有密度**）、截面、Tie／接觸、邊界條件、負載、靜態分析步。
   - 每個零件要是獨立的 Part，報告會依 Part 名稱分零件統計。
   - Field Output 要有 S（應力）、U（位移）；RF／節點力用於驗證外力功。
3. VS Code 開 `FEA-AI` 資料夾 → `Ctrl+Shift+P` → **Tasks: Run Task** → **FEA: 分析目前 PrePoMax 模型（求解＋評估）**。

## 程式會做的
1. 檢查模型有沒有零件、材料、截面、分析步，單位系統是否已定義；缺少就停止並告訴你缺什麼。
2. 新增（或沿用）求解工作 `AutoFEA` 並求解。**不改你的模型設定、不存檔**（只多一個 Job）。
3. 把 `.inp`、`.frd` 複製到 `FEA-AI\results\<模型名稱>\`。
4. 評估並輸出 `results\<模型名稱>\評估結果\report.md`、`parts.csv`、`hotspots.csv`、`ai_summary.txt`；執行紀錄在 `run_log.txt`。

## 第一次執行後
`results\<模型名稱>\fea_config.json` 會自動產生，**容許值、材料類別、權重請自己填**（程式不替你假設）：
- `material_class`：`ductile`（結構鋼，von Mises）／`brittle`（灰鑄鐵，最大主應力）
- `allowable`：MPa；`safety_factor_required`；`weights`；`exclude_bc_radius`（mm）；`moving_axis`
未填容許值的零件不計算強度利用率，風險佔比只依剛性貢獻。

填完後執行 **FEA: 只重新評估（改完 fea_config.json 後）**，不會重新求解。

## 已知限制
- `.frd` 必須是 ASCII（PrePoMax 3.0 起可輸出二進位，遇到會提示）。
- 支援元素：C3D4、C3D10、C3D8、C3D20（含 R）。
- 有接觸（非線性）時，剛性貢獻佔比只能當參考。
