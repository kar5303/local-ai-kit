# 工具機結構分析結果評估工具：判斷邏輯規格 v0.1

適用：PrePoMax（CalculiX）靜態分析結果
目的：讀取分析結果 → 依零件計算強度、剛性、質量／慣性指標 → 排出風險佔比與優化優先順序 → 產出給設計者的建議

> 本規格只使用「可由分析結果計算出的數值」與「使用者設定的參數」。所有門檻值、容許值、權重都由使用者在設定檔中指定，程式不自行假設。

---

## 1. 可從 PrePoMax / CalculiX 取得的資料

| 資料 | CalculiX 輸出關鍵字 | 寫入檔案 | 用途 |
|---|---|---|---|
| 節點座標、位移 | `*NODE FILE` U | .frd | 變形量、TCP 位移 |
| 應力張量 | `*EL FILE` S（平均到節點） | .frd | Mises、主應力 |
| 應變能密度 | `*EL FILE` ENER | .frd | 零件內的剛性熱區位置 |
| **零件總應變能** | `*EL PRINT` ELSE，TOTALS=ONLY | .dat | 剛性貢獻佔比 |
| **零件體積** | `*EL PRINT` EVOL，TOTALS=ONLY | .dat | 核對 |
| **零件質量、重心、質量慣性矩** | `*EL PRINT` EMAS，TOTALS=ONLY | .dat | 質量佔比、慣性 |
| 零件分組 | .inp 中的 Element Set | .inp | 依零件分區 |

依據：CalculiX 手冊 `*EL PRINT`：整個元素的變數包含內能 ELSE、體積 EVOL、質量與對全域軸的質量慣性矩 EMAS；選 TOTALS=YES 或 ONLY 時，會計算該元素集合的重心，以及通過重心、對全域軸的質量慣性矩。ENER／ELSE 才會觸發內能計算。

PrePoMax 端需要：
1. 每個零件是獨立的 Part（.inp 會有對應的 Element Set）
2. Field Output 勾選 U、S、ENER
3. 為每個零件加入 `*EL PRINT`（ELSE、EVOL、EMAS，TOTALS=ONLY）——用 PrePoMax 的 CalculiX 關鍵字編輯功能加入
4. 材料要設定密度（否則 EMAS 為 0）

## 2. 使用者設定檔（config）

| 項目 | 說明 |
|---|---|
| parts | 零件清單：Element Set 名稱 → 顯示名稱（例：BASE → 底座） |
| material_class | 每個零件屬於 `ductile`（結構鋼）或 `brittle`（灰鑄鐵） |
| allowable | 結構鋼：降伏強度；灰鑄鐵：抗拉強度（依公司標準填入） |
| safety_factor_req | 要求的安全係數 |
| moving | 零件是否為移動件，以及隨哪一軸移動（例：SADDLE → Y） |
| weights | 綜合排名權重：強度 w_s、剛性 w_k（使用者指定） |
| regions | （選填）零件內的區域名稱，用座標範圍定義（例：底座導軌安裝面） |
| exclude_sets | 邊界條件、施力點的節點集合，計算熱點時排除其周圍 |
| exclude_radius | 排除半徑（mm） |
| tcp | （選填）刀尖點與工作台的節點集合、施加力大小，用來算迴路剛性 |

## 3. 指標定義（每個零件 i）

### 3.1 強度
| 材料類別 | 評估應力 σ_eval | 對照值 |
|---|---|---|
| ductile（結構鋼） | von Mises 應力 | 降伏強度 |
| brittle（灰鑄鐵） | 最大主應力（取拉應力） | 抗拉強度 |

- σ_eval 取零件內節點值的 **第 99 百分位數**（排除 exclude_sets 半徑內的節點），避免網格奇異點
- 同時記錄最大值與位置，供工程師核對
- 應力利用率 `UR_i = σ_eval_P99 / (allowable / safety_factor_req)`
- `UR_i ≥ 1` → 標記「不符合強度要求」，不論排名

### 3.2 剛性（應變能佔比）
- `SE_share_i = ELSE_i / Σ ELSE × 100%`
- 依據：線性靜力、外力加載時，柔度（外力所作的功 F·u）等於 2 × 總應變能，因此各零件的應變能佔比 = 各零件對整機柔度的貢獻佔比。
- 限制：位移邊界條件加載（強制位移）時，此對應關係不成立，報告需標註

### 3.3 迴路剛性（選填，需設定 tcp）
- `k_loop = F / δ_rel`，δ_rel 為刀尖點與工作台在施力方向的相對位移
- 依據：工具機文獻以刀尖點與工作台相對變形計算的靜態迴路剛性，作為整機靜態性能指標

### 3.4 質量與慣性
- `mass_share_i = m_i / Σ m × 100%`（m_i 來自 EMAS）
- 每個零件的重心座標、通過重心的質量慣性矩（來自 EMAS TOTALS）
- 移動件：彙整各軸的移動質量總和（同一軸上所有 moving 零件的質量相加）

### 3.5 剛性—質量效率比（本工具定義的指標）
- `eff_i = SE_share_i / mass_share_i`
- `eff_i > 1`：該零件對柔度的貢獻大於其質量比例 → 優先補強的候選
- `eff_i < 1` 且 `UR_i` 低：質量比例大於其柔度貢獻 → 減重的候選（移動件優先，因移動質量影響加減速）
- 注意：此為本工具為排序所定義的比值，不是業界標準指標，報告中會註明

## 4. 綜合排名與風險佔比

```
正規化：UR_norm_i = UR_i / max(UR)
綜合分數：score_i = w_s × UR_norm_i + w_k × (SE_share_i / 100)
風險佔比：risk_share_i = score_i / Σ score × 100%
```
- 權重 w_s、w_k 由使用者設定
- 報告中列出公式與權重，設計者可追溯每個百分比的來源
- 風險佔比是「相對優先順序」，不是失效機率

---

## 5. 零件內的位置判斷

1. 在零件內取 ENER（應變能密度）與 σ_eval 排名前 N% 的節點（N 由使用者設定）
2. 以距離分群（群距由使用者設定），每群計算：中心座標、群內最大值、群內應變能總和
3. 若有設定 regions，依座標範圍對應成區域名稱（例：「底座導軌安裝面」）
4. 同一零件內依群內應變能總和排序，取第 1、第 2 名

---

## 6. 建議規則（依計算結果套用）

| 條件 | 建議類型 |
|---|---|
| UR ≥ 1 | 必須處理：強度不足，列出熱點位置 |
| risk_share 第 1 名 | 第一優先優化零件；附零件內第 1、2 熱區位置 |
| risk_share 第 2 名 | 第二優先優化零件；附熱區位置 |
| eff > 1 | 建議補強（該零件剛性貢獻相對其重量偏弱） |
| eff < 1 且 UR 低，且為移動件 | 可評估減重 |
| UR 高但 SE_share 低 | 屬局部應力集中：建議局部修改（倒角、肋板），非整體加強 |

## 7. 輸出

- Excel：
  - 「總表」：零件、風險佔比、排名、UR、SE_share、mass_share、eff、建議類型
  - 「強度」「剛性」「質量慣性」「熱區位置」各一頁
- AI 報告用摘要（純文字表格，幾十行）：交給本機模型或 Copilot 撰寫建議文字
- 報告固定附註：分析條件、公式、權重、限制

---

## 8. 驗證步驟

1. 懸臂梁：比對 ELSE 總和與 ½·F·δ（手算）
2. 兩零件組合：比對 EMAS 質量與 密度 × 體積
3. 簡化的底座＋鞍座模型：工程師檢查排名是否合理
