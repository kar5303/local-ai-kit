# 全自動分析：只放 STEP，其他全部自動

## 你要做的
1. PrePoMax 3.0.1 開著，Automation 伺服器啟用，token 放在 `mcp\prepomax_token.txt`。
   PrePoMax 目前的模型若有未存檔的修改，程式會停止（不動你的工作）。
2. 把組件 STEP 放進 `FEA-AI\input\`（取最新的一個檔）。
   - 零件名稱含材料代號（FC250、FC300、S45C、SS400，不分大小寫，例如 `BASE_FC300`）就套用該材料。
   - **沒有代號的零件照樣會跑**，使用 `rules\materials.json` 的 `default_when_no_code`（目前 FC300），報告的材料欄會標「（預設）」並列出是哪些零件。
   - 代號、數值、預設材料都在 `rules\materials.json`，可自行增修；`default_when_no_code` 設成 null 則改為遇到沒有代號就停止。
3. （建議先做）VS Code → 終端機 → 執行工作 → **FEA: 檢查 STEP 零件名稱（不需 PrePoMax）**：幾秒內列出程式讀到的每個零件名稱、組件路徑、材料代號與位置。中文名稱顯示正確再往下。
4. VS Code → 終端機 → 執行工作 → **FEA: 全自動分析 input 資料夾的 STEP**。
5. 結果在 `FEA-AI\results\<STEP 檔名>\報告.md`（另有 `model.png`、`summary.json`、各工況 `.inp/.frd` 與評估資料夾、`auto_model.pmx`）。

## 程式自動判斷的項目（每項都會在報告寫出依據；判斷不成立就停止並說明）
| 項目 | 判斷方法 |
|---|---|
| 零件名稱 | 支援 STEP 標準 \X2\ 編碼、UTF-8、Big5（CP950）、GBK（CP936）的中文名稱。PrePoMax 匯入 STEP 會把零件命名為 Solid_part-N，所以程式自己讀 STEP 的零件名稱，以「STEP 實體頂點落在 PrePoMax 零件包圍盒內」對應後改名；讀不到或對應不上時沿用 Solid_part-N 繼續跑 |
| 材料 | 零件名稱中的材料代號 → `rules\materials.json`（JIS / EN 1561 規格值，附出處）；沒有代號 → 預設材料，報告標示 |
| 網格 | PrePoMax 預設網格（二次元素） |
| 零件接合 | PrePoMax「搜尋接觸對」（Tie、依零件分組）；另以平面幾何判斷交叉比對 |
| 重力方向與支撐面 | 對每個候選方向檢查：C1 最低處的面只屬於一個零件、C2 該零件是最重零件、C3 組件重心投影落在支撐面範圍內；多個方向通過時取 C4「承重接合面（法向與重力平行）面積比例」最大者，差距不足 0.15 就停止 |
| 浮動零件 | 沒有經由 Tie 連到支撐零件的零件 → 停止 |
| 切削力位置 | 圓柱面佔表面積 > 50% 的零件、端面成對、自由端（未接合）正對另一零件平面 → 主軸端與工作台面；多個候選取距離最短。找不到時（例如單一零件）→ 離支撐面最遠的未接合平面，報告標示需確認 |
| 單一零件的重力方向 | 沒有接合面可比較時，取通過 C1～C3 中支撐面積最大的方向，報告標示需確認 |
| 支撐條件 | 偏剛：支撐面全固定；偏柔：支撐面只限垂直＋兩個節點限制水平剛體運動。兩種都算，比較結論是否一致 |
| 工況 | LC0 自重；LC1～LC3 主軸端 +1000 N、工作台面 −1000 N，沿 X、Y、Z |

## 報告內容（`報告.md` 依序）
1. **結論摘要**：剛性（三方向）、最弱方向、最需要修改的位置與佔比、剛性提高 10% 的效果、零件優先順序、兩種支撐是否一致、減重檢討對象、需確認的自動判斷
2. **修改位置建議總表**：前 10 個位置（零件、上/中/下段、座標範圍、三方向佔比、平均、累計、等級 A～D、修改效果）
3. **零件層級**：剛性、能量守恆檢查、各零件質量、剛性貢獻、效率比、強度利用率、等級
4. **計算原理與驗證方法**：公式與自行驗算步驟（完整說明見 `計算原理與驗證方法.md`）
5. **附錄**：自動判斷過程

## 限制
- 接合一律 Tie（不分離、不滑動），導軌、螺栓的局部剛性未建模
- 切削力工況用 1000 N 單位力：剛性與佔比與力大小無關，但不判斷強度
- `.frd` 須為 ASCII
