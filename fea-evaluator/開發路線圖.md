# 開發路線圖：從單體零件到整機結構的自動評估

## 目標
1. **單體零件**：靜態分析自動化，判斷剛性是否足夠、是否過設計
2. **修改建議**：依風險等級指出需要修改的零件與位置（第一、第二優先）
3. **整機結構**：多零件組合，各零件的剛性貢獻、質量／慣性佔比、整機迴路剛性

## 工作原則
- 先在家用電腦建置並驗證，通過後再帶到公司（兩邊環境相同）
- 每一階段都要有驗證案例（見 `驗證紀錄.md`），數值和理論解或外力功對照
- 所有門檻值、容許值、權重由使用者設定，程式不自行假設

## 階段 1：單體零件判斷（進行中）
**新增的判斷項目**
| 判斷 | 定義 | 使用者要提供 |
|---|---|---|
| 強度 | 利用率 UR_σ = P99 應力 ÷（容許值 ÷ 安全係數） | 容許值、安全係數 |
| 剛性 | 利用率 UR_δ = 指定點位移 ÷ 容許位移（或 k_目標 ÷ k_實際） | 指定點（節點集合）、方向、容許位移或目標剛性 |
| 過設計 | UR_σ 與 UR_δ 都低於使用者設定的下限 | 下限值 |
| 質量 | 質量、重心、慣性矩 | 材料密度 |

**驗證**：V-002b、V-003（剛性對照 3EI/L³）、V-004（灰鑄鐵）、V-005（四面體網格）

## 階段 2：風險等級與修改位置
**風險等級（門檻由使用者設定）**
| 等級 | 條件 | 意義 |
|---|---|---|
| A | UR_σ ≥ 1 或 UR_δ ≥ 1 | 不符合要求，必須修改 |
| B | 介於「注意門檻」與 1 之間 | 接近上限，建議檢討 |
| C | 介於下限與注意門檻之間 | 正常 |
| D | 低於下限 | 過設計，可評估減重 |

**修改位置**：零件內依應變能密度與應力分群，列出第 1、第 2 熱區（座標＋區域名稱）；區分「整體剛性不足」與「局部應力集中」

**驗證**：V-006（含孔平板，熱區定位）

## 階段 3：自動化串接（PrePoMax 3.0 起有 MCP）
| 方式 | 依據 |
|---|---|
| **PrePoMax Automation Server（MCP）** | PrePoMax 3.0.0 起提供「MCP server support, so AI assistants can drive a PrePoMax session」；開啟方式：Tools → Automation Server，位址預設 http://127.0.0.1:8756/mcp，需 Bearer token（Tools → Settings → Automation） |
| PrePoMax Python | 3.0.0 起支援 Python 腳本執行、把指令歷程轉成 Python 腳本 |
| PrePoMax 命令列重新產生（`-r`，PrePoMaxCmd.exe） | v2.1.7 起提供 |
| 評估程式 | `fea_eval.py` 讀取 .inp/.frd 並輸出報告 |
| Cline 串接 | Cline 以 streamableHttp 連到 PrePoMax 的 MCP；評估程式由 Cline 在終端機執行 |

注意：PrePoMax 3.0.0 新增 binary .frd 輸出；`fea_eval.py` 目前只讀 ASCII .frd（V-001 的檔案為 ASCII）。

## 階段 4：整機結構
- 多零件：各零件應變能佔比（剛性貢獻）、質量佔比、效率比、風險佔比排名
- 移動件：各軸移動質量、慣性
- 迴路剛性：刀尖點與工作台相對位移
- 模態（之後）：自然頻率、各模態下的零件應變能分佈

**驗證**：V-007（兩零件串聯，解析解）
